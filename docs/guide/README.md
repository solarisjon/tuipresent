# tuipresent guide

Documentation for people writing and giving talks with tuipresent. Read the pages in order if you're new, or jump straight to the reference.

| Page | What's in it |
|------|--------------|
| [Getting started](getting-started.md) | Build tuipresent, write a three-slide deck step by step, check it and present it |
| [Authoring](authoring.md) | Every slide construct with an example and its gotchas, plus advice on designing slides for a terminal |
| [Presenting](presenting.md) | Keys, a speaker-notes window in kitty or ghostty, live reload, live demos, fitting the projector, troubleshooting |
| [Reference](reference.md) | Tables of every flag, key, front-matter key, directive, image option, exec rule, transition and layout number |

Also useful:

- [`examples/`](../../examples/README.md): complete decks to copy from. Start with `examples/tour.md`, which demonstrates each feature next to its source.
- [`docs/AGENT_GUIDE.md`](../AGENT_GUIDE.md): the same material written for AI coding agents that generate decks.
